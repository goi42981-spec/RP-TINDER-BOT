# RP Tinder Bot

Telegram-бот для РП-проекта. Принимает анкету у пользователя через кнопки и сохраняет в SQLite для последующего матчинга.

## Что умеет

- Проверяет, состоит ли пользователь в указанном РП-чате (`REQUIRED_CHAT_ID`). Если нет — просит вступить.
- Запускает анкету через `/start` → кнопка «Заполнить анкету».
- 4 шага анкеты:
  1. Пол персонажа: **Ж / М / Другое** (inline-кнопки)
  2. Предпочитаемый пол: **Ж / М / Другое** (inline-кнопки)
  3. Юзернейм (текст; парсится в формат `@nickname`)
  4. Ссылка на анкету (валидация: должен быть URL с `http(s)://`; если прислали текст анкеты вместо ссылки, бот просит ссылку ещё раз)
- Сохраняет/обновляет анкету в SQLite (`rp_bot.db`).
- `/me` — показывает твою текущую анкету.
- `/cancel` — отменить заполнение.

## Запуск локально

1. Поставить Python 3.10+
2. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Создать бота у [@BotFather](https://t.me/BotFather), получить токен.
4. Узнать `chat_id` РП-чата:
   - Добавь бота в чат как админ (минимум с правом видеть участников).
   - Напиши в чат любое сообщение, отправь его боту [@username_to_id_bot](https://t.me/username_to_id_bot), или используй [@RawDataBot](https://t.me/RawDataBot).
   - ID группы/супергруппы выглядит как `-1001234567890`.
5. Скопировать `.env.example` → `.env` и заполнить:
   ```bash
   cp .env.example .env
   # отредактировать BOT_TOKEN, REQUIRED_CHAT_ID, REQUIRED_CHAT_LINK
   ```
6. Запустить:
   ```bash
   python bot.py
   ```
